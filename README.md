# DSA-MiniProject
Data structures mini project/final.

1. Project Overview: Describe your project in 1–2 sentences.
    - This project aims to develop several neural networks for language identification of French, English, and Spanish and compares the confidence of results depending on input text, shown in two generated graphs.

2. Relevant Data Structure Concept: Which data structure concept(s) were most relevant to this project?
    - Hash tables in the form of the Python dictionary are at the heart of this project. Lists (with linked lists/arrays as the underlying ADT in Python) were also used, particularly in the parsing and chunking of training texts. 
    2. (1) Application of DS: How did you apply that concept in your implementation?
        - I used a dictionary in my find_unique function (implemented to verify that the parsing function was working and that my underlying logic was correct) as well as mainly in my build_global_vocab function. In both cases, the hash table implementation of Python's dictionary data type made the ordering of unique words incredibly fast with O(1) lookup and insertion thanks to the underlying hash function's efficiency. I learned that simply using this dictionary would be most efficient through the AVL HW09 activity we previously completed that showed the speed of the dictionary in comparison to other data structures.
        - For lists, as previously stated, the main usecase came in the data mining part of the project.

3. Project Workflow: Explain the end-to-end workflow (e.g., expected inputs, core processing logic, and expected outputs).
    - This project can be divided into three main parts:
        - Data mining
            - The scraper.py file is meant to only be run once to scrape data from pdfs of the bible. Two versions were used that scanned different parts of distinct pdfs to get the necessary information from each pdf bible version
                - Text cleaning was also performed on the data to remove punctuation and digits/only keep relevant characters. I used **AI** to help with the function for the french bible parsing as the parsing was made complicated by the pdf used.
            - The data.py file chunks a given file input into chunks of a specified length, the find_unique arranges the unique words, while encode tokenizes a given string based on a vocabulary dictionary
            - in execute.py, build_global_vocab builds on find_unique in data.py and does a similar process for all file data
        - Model training
            - network.py sets up two classes that link/prepare the dataset generated by the previous two files with/for the training to come. This is done through initializing initial tensors per dataset and initializing the neural neetwork's input, hidden, and output layers as well sa forwarding logic
            - train.py was generated with the help of **AI** and trains the model with pytorch, calculating loss per epoch and ultimately outputting the results (including time elapsed per epoch) in a print statement while saving the .pth models in a folder so that this process only needs to happen once.
        - Execution
            - the evaluate_confidence function is at the heart of the program and uses softmax to evaluate the accuracy of results
                - the confidence results are then outputted on graphs using matplotlib
            - this is all called in the main file that can be ran with ./main 
                - prompts user for text to be evaluated
                - fetches the necessary training data to use the most updated models to call the evaluate_confidence function
                - evaluate_confidence takes care of this


4. Performance: What is the average running time of your project (time complexity and/or observed runtime)?
    - The O(1) constant time complexity for dictionary queries/insertions makes the underlying data structures manageable. However, because of the use of tensors, the actual runtime for each epoch during training was around 40 seconds each time for the bible training and a few milliseconds for the simple quotes. If the number of neurons in the network was lowered, the result might be less accurate, but the runtime for the training would likely decrease.
